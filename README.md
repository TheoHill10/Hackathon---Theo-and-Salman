# Tic Tac Toe
Creating naughts and crosses 


### How to run the app
 To run the app, please do the following steps:
 1. In your terminal, go to a folder of your choosing and run the following command
 ```
 git clone git@github.com:TheoHill10/Hackathon---Theo-and-Salman.git
 ``` 
2. Once created, enter the folder using the following
```
cd Hackathon---Theo-and-Salman/
```
3. run the following command in your terminal to play the game
```
node index.js
```
### How to play
- You will automatically be naughts and get to go first.
- To place a naught you will type an input of where you would like to go.
- The inputs will need to be in the following format:
Top_R, Mid_M, Bot_L. E.g which row you want to go on followed by which column it is in.
- The computer will then have it's turn and so on.
- The winner is the person who gets three in a row first.
